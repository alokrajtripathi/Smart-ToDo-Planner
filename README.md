# Smart To-Do & Daily Planner

A modern, responsive task management application built using React.js and LocalStorage. It helps users organize daily activities, manage priorities, track deadlines, and monitor task completion progress.

## Project Overview

The Smart To-Do & Daily Planner is a frontend-based productivity application that allows users to create, update, delete, filter, and manage their daily tasks.

It uses browser LocalStorage to save task information, ensuring that data remains available even after refreshing the page.

## Technologies Used

- React.js
- Vite
- JavaScript
- Tailwind CSS
- Lucide React Icons
- Browser LocalStorage

## Key Features

1. Add new tasks.
2. Edit existing tasks.
3. Delete individual tasks.
4. Mark tasks as completed.
5. Set task priorities (High, Medium, Low).
6. Assign due dates to tasks.
7. Highlight overdue tasks.
8. Search tasks by title.
9. Filter tasks (All, Active, Completed).
10. Sort tasks by priority, due date, and creation date.
11. Bulk task selection.
12. Mark multiple tasks as completed.
13. Delete multiple selected tasks.
14. Clear all completed tasks.
15. Dashboard with task statistics and progress tracking.
16. Automatic data persistence using LocalStorage.

## Installation and Setup

### Prerequisites

- Node.js
- npm
- Visual Studio Code

### Step 1: Clone or Download the Project

Download the project folder to your computer.

### Step 2: Open Terminal

Navigate to the project directory.

### Step 3: Install Dependencies

```bash
npm install
```

### Step 4: Start Development Server

```bash
npm run dev
```

### Step 5: Open in Browser

Open the local URL displayed in the terminal, usually:

http://localhost:5173/

## Data Storage

The application uses browser LocalStorage to store task information.

Storage Key:

`smart-todo-tasks`

Tasks remain saved after refreshing the browser on the same browser and origin.
